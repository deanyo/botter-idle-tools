Share what you make

The item wizard downloads a JSON proposal with your design, optional credit and notes. Send the file to the developer through the community channel where you received this link. Every proposal gets a design and balance review before it enters the game.

Run the public tools locally
git clone https://github.com/deanyo/botter-idle-tools.git
cd botter-idle-tools
python3 -m http.server 8080

Open http://localhost:8080/. Developers in the game repo serve its root and open /tools/ instead.
